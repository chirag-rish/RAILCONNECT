# SIH26028 — ML Pipeline for Dynamic ETA Prediction

## Overview

This directory contains the machine learning pipeline for predicting section-level train delays in the RailConnect platform. The model predicts `target_delay_minutes` (actual travel time minus scheduled travel time) for each railway section a train traverses.

## Directory Structure

```
server/ml/
├── train_model.py          # Main training pipeline (model comparison + selection)
├── extend_dataset.py       # Synthetic dataset generation v2
├── diagnose.py             # Diagnostic analysis script
├── debug_data.py           # Data exploration helper
├── models/                 # Saved model artifacts
│   ├── eta_xgboost_model.json      # Trained XGBoost model
│   ├── preprocessing.joblib         # Fitted encoders and feature config
│   ├── feature_schema.json          # Feature definitions for inference
│   ├── model_metadata.json          # Full model metadata
│   ├── evaluation_results.json      # All model comparison results
│   ├── error_analysis.json          # Per-segment error breakdown
│   └── feature_importance.json      # Feature importance rankings
├── tests/                  # Python test suite
│   └── test_pipeline.py    # ML pipeline tests
└── README.md               # This file
```

## Quick Start

```bash
# 1. Install Python dependencies (if not already installed)
pip install pandas numpy scikit-learn xgboost joblib

# 2. Regenerate dataset (optional — dataset is pre-generated)
python server/ml/extend_dataset.py

# 3. Run training pipeline
python server/ml/train_model.py

# 4. Run tests
python -m pytest server/ml/tests/ -v
```

## Features

### Base Features (17 numeric + 3 categorical)
| Feature | Type | Description |
|---------|------|-------------|
| accumulated_delay_entering | numeric | Delay accumulated before entering section |
| prev_section_travel_time | numeric | Actual travel time of previous section |
| prev_section_delay | numeric | Delay from previous section |
| stations_travelled | numeric | Number of stations traversed so far |
| stations_remaining | numeric | Number of stations remaining |
| section_distance | numeric | Distance of section in km |
| typical_speed | numeric | Typical speed limit in km/h |
| max_speed | numeric | Maximum speed limit in km/h |
| signal_count | numeric | Number of signals in section |
| level_crossings | numeric | Number of level crossings |
| hour | numeric | Hour of day (0-23) |
| day_of_week | numeric | Day of week (0=Mon, 6=Sun) |
| is_weekend | binary | 1 if Saturday or Sunday |
| event_active | binary | 1 if operational event active |
| event_speed_limit | numeric | Speed limit from event |
| historical_mean_travel_time | numeric | Rolling average past travel times |
| historical_mean_delay | numeric | Rolling average past delays |
| section_type | categorical | SingleLine/DoubleLine/TripleLine/Quadruple |
| gradient_profile | categorical | Flat/Mild/Steep |
| event_type | categorical | Type of operational event |

### Engineered Features (13 additional)
| Feature | Description |
|---------|-------------|
| accumulated_delay_x_distance | Delay × distance interaction |
| accumulated_delay_x_speed | Delay / speed interaction |
| delay_rate | Delay per station traversed |
| speed_margin | max_speed - typical_speed |
| speed_limit_ratio | event_speed_limit / max_speed |
| section_travel_time | Scheduled travel time (distance/speed) |
| delay_fraction_of_travel | Delay as fraction of scheduled time |
| hour_sin, hour_cos | Cyclic time encoding |
| signals_per_km | Signal density |
| crossings_per_km | Level crossing density |
| prev_delay_positive | Positive part of previous delay |
| accumulated_delay_squared | Nonlinear delay effect |
| is_peak_hour, is_night | Time-of-day indicators |
| event_speed_ratio | Event speed restriction magnitude |
| section_type_gradient | Section type × gradient interaction |

## Models Compared

| Model | Validation MAE | Test MAE | Test RMSE | Test R² |
|-------|---------------|----------|-----------|---------|
| Baseline (historical_mean_delay) | 4.4745 | 4.5397 | 6.0886 | 0.0670 |
| Ridge Regression | 4.1876 | 4.2875 | 5.8355 | 0.1430 |
| Random Forest | 4.1929 | 4.2655 | 6.0186 | 0.0884 |
| **XGBoost Residual (selected)** | **4.1290** | **4.2561** | **6.1170** | **0.0583** |
| XGBoost Direct | 4.1821 | 4.2932 | 6.1424 | 0.0505 |

**Selected model: XGBoost Residual** — beats baseline by 0.2836 min (6.2%) on the test set.

## Reproducibility

- **Random seed:** 42
- **Dataset version:** eta_dataset_v1 (5760 rows)
- **Chronological split:** 70% train / 15% validation / 15% test
- **No test-set tuning:** Test set used only for final one-time evaluation

## Synthetic Data Disclaimer

This model was trained on structurally realistic synthetic railway telemetry generated by simulation. It is designed to demonstrate the ML pipeline architecture and is replaceable with real Indian Railways operational data.
